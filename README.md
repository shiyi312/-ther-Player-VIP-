## 📖 项目概述

**Æther Player** 是一个强大的用户脚本，旨在帮助用户免费观看各大视频网站的 VIP 内容。通过集成多个第三方解析接口，该脚本能够绕过视频网站的会员限制，让用户享受免费的视频观看体验。

与同类脚本相比，Æther Player 拥有**独特的毛玻璃美学设计**、**彻底静音（直接删除原生视频）**、**自定义解析源排序**和**记忆上次选择**等独家优势。

## 🎮 使用说明

### 基本操作

| 操作 | 说明 |
|------|------|
| **单击悬浮球** | 打开/关闭解析源面板 |
| **拖拽悬浮球** | 任意拖动悬浮球到屏幕任何位置 |
| **选择解析源** | 在面板中点击任意解析源名称，立即切换 |
| **刷新播放器** | 点击面板中的「↻ 刷新」按钮 |
| **打开选集** | 点击播放器右侧悬浮的「📋 选集」按钮（或悬浮球面板内的选集按钮） |
| **切换集数** | 在侧边选集栏中点击任意集数 |

### 自动解析

- 脚本默认开启「自动解析」，页面加载后自动使用第一个解析源（虾米）进行播放
- 若当前解析源加载失败，脚本会自动按顺序尝试下一个解析源
- 您可以在面板中关闭「自动解析」，改为手动选择

### 记忆功能

- 您手动选择的解析源会被自动保存
- 刷新页面后，脚本会优先使用您上次选择的解析源
- 无需每次重新选择

## ❓ 常见问题

### Q1: 脚本安装后没有生效？

**A:** 请检查以下几点：
1. 确认脚本管理器已启用（Tampermonkey 图标应为彩色）
2. 确认当前页面是支持的视频网站（爱奇艺、腾讯、优酷等）
3. 尝试刷新页面
4. 检查脚本管理器中脚本是否处于「已启用」状态

### Q2: 播放器没有加载出来？

**A:** 
1. 尝试点击面板中的「↻ 刷新」按钮
2. 切换其他解析源试试
3. 检查网络连接是否正常
4. 如果持续失败，可尝试刷新整个页面

### Q3: 选集列表为空或显示「未识别到选集」？

**A:** 
1. 点击选集面板中的「刷新选集列表」按钮
2. 尝试切换集数后再切回来
3. 部分页面需要等待页面完全加载后再打开选集

### Q4: 脚本和 AdBlock 等插件冲突吗？

**A:** 一般不会冲突。但如果遇到异常，可尝试暂时禁用 AdBlock 后重试。

### Q5: 脚本会收集我的个人信息吗？

**A:** **不会。** 本脚本完全开源，所有代码公开透明。脚本仅在本地运行，不收集任何用户数据，不发送任何请求到第三方服务器（除了解析接口调用）。
